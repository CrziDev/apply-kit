# Apply Kit

A Firefox add-on that saves your links, repetitive answers, and resume so you can fill job applications in one click.

- **Links:** GitHub, LinkedIn, portfolio. Click to copy.
- **Text:** bio, "Why this role?", phone, and other answers you type often. Click to copy.
- **Files:** resume and cover letter. Click to attach to the page's upload field.

## Use
- Hover an item to edit or delete it. Click **+** to add one.
- **Add files** with the **Add / manage files in a tab** button on the Files tab. (Firefox closes popups when a file picker opens.)
- **Attach a file:** click the form's upload button and cancel the dialog, then open Apply Kit → Files and click your file. If a site blocks it, hover the file and use **Download**.

## Privacy
Everything stays in your browser. Nothing is sent anywhere.
